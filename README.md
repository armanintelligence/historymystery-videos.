# historymystery-videos.

Daily Shorts for the **historymystery2027** channel: unexplained history, investigated with science.

- `CHANNEL_RULES.md`: content rules (no living faces, no nudity, no music), style and format
- `DAILY_RUN.md`: step-by-step daily production and scheduling
- `LONG_RUN.md`: the daily long video (7 PM IST)
- `topics.md`: topic backlog
- `pipeline/`: code that draws the scenes, narrates, adds natural sound and renders the video
- `episodes/<date>-<topic>/`: one folder per Short (scenes, sources)
- `long/<date>-<topic>-long/`: one folder per long video
- `videos/`: finished videos. Metricool fetches them from here by their public link, on the `daily` branch.
